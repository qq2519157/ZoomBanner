# ZoomBanner

Banner 下拉放大效果，搜索栏下拉渐变色。

## 效果展示

![image](https://github.com/qq2519157/ZoomBanner/blob/master/app/src/main/res/gif/example.gif)

## 功能特性

- Banner 下拉刷新时放大缩放效果
- 搜索栏随下拉/滚动渐变透明度
- Banner 自动轮播
- 嵌套滚动 + RecyclerView 列表

## 运行

使用 Android Studio 打开项目，连接设备直接运行即可。轮播图使用本地图片，无需后端接口。
